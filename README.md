# Featured Project

## Operations Intelligence Control Tower

Interactive operations decision-support system designed for high-volume, SLA-driven environments.

The application converts operational data into:

- Executive KPI monitoring
- SLA and capacity exception detection
- Backlog and utilization analysis
- Site and vendor performance comparison
- Root-cause signals
- Configurable operational thresholds
- Prioritized management actions
- Multi-dataset analysis
- User-uploaded operational data analysis

Built with **Python, Pandas, Plotly and Streamlit**, with large synthetic operational datasets for demonstration and testing.

🔗 **Live App:**  
https://operations-control.streamlit.app/

🔗 **GitHub:**  
https://github.com/Vikrantthenge/operations-control-tower
